# SubmitVideoGenerationJob Example Project

The is a example project for SubmitVideoGenerationJob.

**It is recommended to use the default credential. For more credentials, please refer to: [Managing Access Credentials](https://www.alibabacloud.com/help/en/sdk/developer-reference/v2-manage-python-access-credentials)**

## Prerequisites

- Download and extract the code for the required language;

- *The Python version must be 3.7 or later.*

## Execution Steps

After completing the credentials configuration, you can execute the following steps in the **directory where the code was extracted**:

- **Create and activate a virtual environment:**
  ```sh
  python -m venv venv && source venv/bin/activate
  ```

- **Install dependencies:**
  ```sh
  pip install -r requirements.txt
  ```

- **Run code**
  ```sh
  python ./alibabacloud_sample/sample.py
  ```
